Reglas y cómo se juega

Objetivo

Hundir toda la flota del rival antes de que él hunda la tuya.

Flota (cada jugador)

  • Portaviones: 5 casillas
  • Buque: 4
  • Crucero: 3
  • Submarino: 3
  • Destructor: 2

Cómo se juega

  1. Un jugador pulsa Generar mi ID y comparte el código (ej. MA-482910). El otro lo escribe y pulsa Conectar.
  2. Coloca tus barcos: elige uno, haz clic en tu tablero y rota con R (o el botón). También puedes usar Aleatorio. Los barcos no pueden superponerse ni salirse.
  3. Pulsa Estoy listo. Cuando ambos estén listos, el anfitrión pulsa Iniciar batalla.
  4. Tras la cuenta regresiva, se juega por turnos: en tu turno elige una casilla de las Aguas enemigas.
  5. Llama = impacto (sigues viendo el resultado); ondas = agua. Cuando todas las casillas de un barco son impactadas, se hunde.
  6. Los turnos se alternan después de cada disparo.
  7. Gana quien hunda primero toda la flota rival.

Consejos

  • Tras un impacto, prueba las casillas vecinas para encontrar la dirección del barco.
  • Dispara en patrón de tablero de ajedrez para cubrir más agua.
